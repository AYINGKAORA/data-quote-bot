# Data Quote Bot

帮我做一个 AI 报价单处理工具的网页：

品牌名：AyingAI，深蓝色+银色科技风，简洁高级；

中间一个大上传框：支持拖拽上传图片/PDF，按钮写"一键整理报价单"；

上传后下方显示结果：客户公司名、产品表格（品名/规格/数量/单价/总价）、注意事项；

表格下方有"下载 Excel"按钮；

页面顶部导航：AyingAI Logo + 菜单（首页、功能、价格、联系）；

中俄双语切换按钮；

手机端也要好看。
